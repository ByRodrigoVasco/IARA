# IARA

Repositório do **Grupo 8**, jogo educativo desenvolvido como
Projeto Integrador do 2º período de Análise e Desenvolvimento de Sistemas - CESAR School (2026.2).

O jogador investiga um caso de horror corporativo envolvendo uma IA fictícia
chamada IARA. Quanto mais questiona as respostas da IA em vez de aceitá-las
automaticamente, mais lógica formal precisa aplicar para provar
inconsistências. A mecânica ensina, ao mesmo tempo, alfabetização/ética em IA e lógica clássica.
